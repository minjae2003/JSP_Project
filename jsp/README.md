# 🏪 Smart GS24 - 통합 편의점 ERP 및 물류 관리 시스템

> **본사 관리자(`manager`)**와 **가맹점주(`owner`)**의 역할을 명확히 분리하여 상품 마스터 등록부터 발주, 입고, 재고 반영, POS 판매 결제까지의 전체 유통 데이터 생명주기를 통합 관리하는 JSP/Servlet 기반 웹 ERP 프로젝트입니다.

---

## 📌 주요 기능 (Key Features)

* **🔒 세션 기반 보안 및 권한 제어 (RBAC)**
  * 세션 내 `role` 값(`manager` / `owner`)을 판별하여 페이지 접근 제한 및 메뉴 동적 제어
  * 비인가 사용자의 URL 직접 접근 시 로그인 페이지(`login.jsp`)로 자동 리다이렉트
  * 로그인 시 점주 세션에 `store_no`(가맹점 코드)를 바인딩하여 점포별 독립 데이터 격리

* **📊 가맹점주 / 관리자 경영 대시보드 (`OwnerMain.jsp` / `ManagerMain.jsp`)**
  * 주요 작업(상품조회, 발주현황, 입고, POS결제)에 빠르게 접근할 수 있는 카드형 UI
  * 접속 중인 계정 ID 및 담당 가맹점 코드 상단 헤더 상시 노출

* **📦 통합 상품 마스터 관리 (`productList.jsp`)**
  * **[관리자]** JavaScript 기반 대분류(냉장/일반) 선택 시 소분류 드롭다운 실시간 동기화 및 상품 추가
  * **[관리자]** 물류 DB 마스터 데이터 개별 삭제 기능 (`productDeletePro.jsp`)
  * **[점주]** 전체 카탈로그 및 표준 출고 단가 조회, 수량 지정 후 즉시 발주 신청 및 POS 결제 연동

* **📝 본사 물품 발주 관리 (`orderInsert.jsp` / `orderPro.jsp`)**
  * 매장 부족 재고 수량을 지정하여 본사 시스템에 발주 요청 생성
  * 점주별 발주 진행 상태(신청 완료, 본사 승인 대기, 출고 준비 등) 실시간 모니터링

* **🚚 매장 실시간 입고 처리 (`purchaseInsert.jsp` / `purchasePro.jsp`)**
  * 본사 승인 물품 입고 완료 시, 해당 매장의 보유 재고 수량 자동 합산 반영
  * 물품 검수 완료 시점의 입고 일시 및 수량 로그 기록

* **🔍 실시간 매장 재고 조회 (`inventoryList.jsp`)**
  * 가맹점 코드(`store_no`) 기준 매장 보유 상품별 실시간 수량 조회
  * 안전 재고 기준 미달 품목 시각적 경고 표시

* **💻 가맹점 POS 판매 결제 시스템 (`salesInsert.jsp` / `pos.jsp`)**
  * POS 화면에서 상품 선택 및 수량 입력 후 결제 완료 트랜잭션 수행
  * 결제 완료 즉시 매장 보유 재고 차감 및 본사/가맹점 매출 데이터 자동 집계
